# 视频取证层本地运行手册（Sprint A）

目标：新人按本文 30 分钟内跑通「证据流 → 找法 → 用法」主链路。所有命令均无需云账号。

## 1. 环境

```bash
# 必备（与 Makefile test-handoff 一致）
/opt/anaconda3/bin/python3.12 -m venv .venv-handoff
.venv-handoff/bin/pip install -r requirements-handoff.txt

# 可选：真实视频本地推理（faster-whisper + RapidOCR，首次运行自动下载模型）
.venv-handoff/bin/pip install -r backend/requirements-local-video.txt

# 抽帧/音轨还需要系统 ffmpeg
brew install ffmpeg
```

密钥只走环境变量 / `backend/.env`（见 `backend/.env.example`），代码与日志不落密钥。

## 2. 三条运行入口

| 命令 | 入口 | 用途 |
|---|---|---|
| `PYTHONPATH=backend .venv-handoff/bin/python backend/scripts/run_review.py --demo --llm mock --out out/demo.json` | 内置演示证据流 | 验证找法+用法全链路，零依赖零模型 |
| `PYTHONPATH=backend .venv-handoff/bin/python backend/scripts/run_review.py --job data/video_mvp/jobs/<id> --llm mock --out out/job.json` | 已识别的 evidence.json | 用旧 MVP 跑批结果验证合并/粗筛/L4/报告 |
| `PYTHONPATH=backend .venv-handoff/bin/python backend/scripts/review_video.py <video.mp4> --industry health_food --llm mock --out out/real.json` | 视频本体 | 真实抽帧+ASR+OCR（需 ffmpeg 与本地模型包） |

配了 DeepSeek key 后 `--llm auto` 自动走真模型（`LLM_API_KEY` / 兼容旧名 `LEX_DEEPSEEK_API_KEY`）。

## 4. 测试

```bash
.venv-handoff/bin/python -m pytest backend/tests -q
```

- 2026-09-17 基线：**392 passed / 3 failed**，3 个失败全在 `test_crawler.py`（与视频链路无关）。

## 5. 当前模块地图

```
backend/app/
├── config.py                 Provider 开关、流水线参数、成本红线（OCR≤20/VLM≤4）
├── pipeline/                 取证层
│   ├── extract.py frames.py  分镜∪2fps 抽帧、pHash 去重回填 span
│   ├── evidence.py           EvidenceUnit / 时间戳换算 / CostRecord
│   ├── merge.py              OCR 跨帧合并（文本相似度 + bbox IoU）
│   ├── interop.py            旧 video-mvp 格式互转
│   └── providers/            能力闸门 + 成本闸门 + mock/local 实现
├── rules/                    找法层
│   ├── lexicon/              L1 49 条 / L2 25 条 / L3 17 条 / L4 5 场景（均未经法务复核）
│   ├── matcher.py            AC 自动机粗筛 + 白名单
│   └── mandatory.py          L4 必备要素 + 显著性
├── ip/                       IP 识别（阶段 2 骨架，2026-09-17）
│   ├── library/ip_library.seed.yaml  18 个权利主体起始清单（待法务确认，暂无参考图）
│   ├── vectors.py            向量检索契约（SSCD/faiss 到位只换实现）
│   ├── detector.py           底库→VLM 双层融合，VLM-only 强制 pending
│   └── prompts.py            结构化 VLM prompt
└── reasoning/                用法层：三态涵摄、六段式报告、类案参照、DeepSeek
```
