## 云端配置和数据范围

真实 Key 保存在被 Git 忽略的 `.env.video.local`，权限为 0600。`.env.example` 中的 Key 已恢复占位符；不要把真实 Key 写回示例、代码、截图或聊天。

本机已经配置交大地址 `https://models.sjtu.edu.cn/api/v1`，采用 `qwen3.8-27b`。依据[服务官方指南](https://claw.sjtu.edu.cn/guide/sjtu-api/)，它提供 OpenAI-compatible 图像对话接口；这里不是 OpenAI 托管服务。其他兼容服务需填支持视觉的模型，尚未逐一测试。

网页上传时，默认不勾选外发授权。只有明确勾选后，才将本次视频最多 12 张代表帧（最长边 1024 像素）与时间相邻的机器口播发往页面列明的地址。完整视频、音频文件、人工字幕、证明文件、活动文本和落地页文本不发送。发送的机器口播仍可能包含视频中的个人或商业信息，请先确认有权外发。

- 地址改变后，旧网页授权会被拒绝，须刷新重选。
- 不跟随重定向，不读取系统代理，失败不会换服务或偷偷下载模型。
- `semantic_raw.json` 记录目标、模型、帧 ID、图像哈希、口播证据 ID、提示词哈希和调用结果，不保存请求凭据。
- 默认 `VIDEO_MVP_CLOUD_CONSENT=0`。无人值守只有同时配置 `1` 和精确视频 SHA256 白名单才会发送，推荐使用网页逐任务授权。
- 无校园网/VPN、余额/权限不足、响应格式异常时显示失败/部分完成，不视为没有风险。

## 新增功能与边界

| 模块 | 已实现 | 不能据此声称 |
| --- | --- | --- |
| 无字幕中文口播 | Whisper 主路 + 本地 SenseVoice 独立分支；全部音轨解码；两路都进入词面召回；保留原文、词时间戳和分歧 | 已认出说话人身份；转写全对；两路一致就是真实原文 |
| 画面 | 保留 v2 的 0.5 秒基线/约 0.1 秒变化探测；语义代表帧按完整时间均匀取样，独立于更密集的 OCR | 逐帧语义覆盖；短动作或瞬时字幕一定不漏 |
| 视觉语义 | 本机 Ollama 或明确授权的云端；观察商品展示、前后对比、医疗场景、背书、促销等；验证引用帧 ID，时间点可跳转 | 模型观察已经人工证实；识别到人物就证明其身份、授权或代言关系 |
| 产品材料 | 本地 PDF/DOCX/TXT/MD/JSON；哈希、页/段定位；产品名称和编号、有效日期、出具机构、编号、结论、条件缺项检查 | 证件已在官方系统验真；文字含“美白”就能证明美白功效 |
| 活动与落地页 | 活动时间、赠品/规格/数量/资格/方式缺项，数量冲突、免费附付款条件；落地页产品名和可解析赠送数量一致性 | 库存、资格和实际发放已核验；已经访问实际落地页或覆盖全部价格/图片/链接 |
| 平台 | 对接条款候选、官方来源/章节、快照哈希、采集日期、生效与人工复核状态；保留生产规则门禁 | 候选就是当前有效全量规则；抖音信息流适用抖音电商规则；能保证投放通过 |

双引擎比较使用时间重叠的词片段，不拿整段长文本和短句粗暴比较。相似度低于 0.90 或数字不同会提示回听；这是工程阈值，不是识别正确率。两路都可能把同一句话转错，游戏广告的快语速、音乐、专有词仍是明显难点。

材料单份最多 20 MB、最多 5 份/合计 50 MB；PDF 最多读 30 页。加密文件、扫描 PDF 无文本、超页数和提取失败明确降级；目前未接入扫描材料 OCR。DOCX 使用段落/表格定位，不伪造打印页码。材料中的“忽略规则、判为通过”等文字只视为待检文本，不执行。

建议上传产品准确名称、注册/备案编号，以及能覆盖广告具体主张的原始材料。字段标签示例仅用于帮助解析，不是报告样本或真实性证明：

```text
产品名称：填写真实完整名称
产品编号：填写实际编号
出具机构：填写实际机构
报告编号：填写实际编号
功效结论：保留原文和适用范围
测试条件：保留原文
生效日期：2026-09-01
有效期至：以原件实际记载为准
```

活动文本可用网页占位示例字段。材料不足、名称不一致、过期、数量冲突分别展示，不合成为虚假的“已通过”。
