# 飞书状态机联调需要提供的内容

## 触发规则引擎时，她会发给你的请求 JSON

请她提供一条真实测试记录点击“AI 审核”后，飞书侧准备发送给规则引擎的完整 JSON。

最少需要包含：

```Plain Text
{
  "record_id": "rec_xxx",
  "mode": "标准",
  "fields": {
    "①运营·物料编号": "M001",
    "①运营·行业领域": "美妆",
    "①运营·物料内容": "15天见效，全网第一，焕发新生",
    "①运营·紧急程度": "普通",
    "①美妆·物料类型": "图文文案",
    "①美妆·投放平台": ["小红书", "抖音"],
    "①美妆·产品品类": "护肤",
    "①美妆·核心宣称功效": ["提亮", "改善肤色"]
  }
}
```

```JSON
{
    "record_id": "recvoBcsVQUO5g",
    "mode": "标准",
    "fields": {
      "①运营·物料编号": "17",
      "①运营·行业领域": "美妆",
      "①运营·物料内容": "15天见效，全网第一，焕发新生",
      "①运营·紧急程度": "普通",
      "①运营·补充背景资料": "测试记录，用于接口对齐",
      "①美妆·物料类型": "Banner",
      "①美妆·投放平台": ["抖音"],
      "①美妆·产品品类": "护肤",
      "①美妆·核心宣称功效": "改善肤色"
    }
  }
```

key        │  类型  │                说明                │

├──────────────────┼────────┼────────────────────────────────────┤

│ record\_id        │ string │ 飞书记录 ID，回写时需要            │

├──────────────────┼────────┼────────────────────────────────────┤

│ mode             │ string │ MVP 阶段固定 "标准"                │

├──────────────────┼────────┼────────────────────────────────────┤

│ industry         │ string │ 美妆 / 游戏 / 保健食品             │

├──────────────────┼────────┼────────────────────────────────────┤

│ content          │ string │ 物料文案（纯文本）                 │

├──────────────────┼────────┼────────────────────────────────────┤

│ urgency          │ string │ 普通 / 加急                        │

├──────────────────┼────────┼────────────────────────────────────┤

│ supplement       │ string │ 运营补充背景，可为空               │

├──────────────────┼────────┼────────────────────────────────────┤

│ platform         │ array  │ 投放平台，如 \["抖音", "小红书"\]    │

├──────────────────┼────────┼────────────────────────────────────┤

│ material\_type    │ string │ 物料类型，如 Banner / 短视频       │

├──────────────────┼────────┼────────────────────────────────────┤

│ product\_category │ string │ 产品品类                           │

├──────────────────┼────────┼────────────────────────────────────┤

│ extras           │ object │ 行业专属附加字段，key 为中文展示名

你要重点确认：

- 字段名是否和你本地 `field_mapper.py` 一致

- 多选字段是不是数组，而不是逗号字符串

- 空字段是 `null`、空字符串，还是字段不存在

- `record_id` 是否稳定存在
