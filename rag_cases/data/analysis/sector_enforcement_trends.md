# 三大领域执法趋势分析

## 游戏领域

* 概率公示合规成为核心监管要求
* 广告宣传用语须准确清楚
* 法院对“欺诈”认定持审慎态度

## 美妆领域

* 医疗用语是美妆广告红线
* 虚假功效宣传处罚力度大
* 医美广告须经审查

## 保健品领域

* 会销模式是重点监管对象
* 普通食品不得宣称疾病预防治疗功能
* 网络营销虚假宣传风险高

## 原文摘录

- （一）游戏领域：监管重点聚焦概率公示与广告内容真实性
- 1. 概率公示合规成为核心监管要求。 从四川某某科技公司案可以看出，监管部门对盲盒、抽奖类游戏的概率公示要求日趋严格。仅对部分代码进行鉴定或公示计算方法，不足以满足合规要求；经营者需确保公示的概率与实际运行概率一致，且鉴定范围应覆盖完整的运行代码。吴某、郝某案中法院通过技术勘验手段验证盲盒概率真实性，为行业提供了合规参考路径。
- 2. 广告宣传用语须准确清楚。 王越案中，市监局依据《广告法》第八条对广告允诺“未准确、清楚、明白”进行处罚，表明游戏广告中的赠送、奖励承诺必须明确告知限制条件，不得以模糊表述误导消费者。朱某伟案中“1000连抽免费自选”的宣传因未说明领取条件而被认定为表达不够准确。
- 3. 法院对“欺诈”认定持审慎态度。 从郭某案、孙某案、许某案、闻某案、刘某案来看，法院在认定游戏广告是否构成民事欺诈时，通常考量以下因素：经营者是否已公示概率或规则；玩家是否在明知规则的情况下持续充值消费；广告宣传是否达到“虚构事实、隐瞒真相”的程度。仅在广告表达不准确但未达到欺诈程度时，法院倾向于驳回消费者的三倍赔偿诉求。
- 4. VIP权益说明须明确清晰。 王某案中，游戏VIP特权专区对vip8和vip9的“专属客服”权益未作明确区分，导致消费者误解，被市监局处以罚款。经营者须确保不同等级权益的说明清晰明确，避免模糊表述。
- （二）美妆领域：重点打击医疗用语与虚假功效宣传
- 1. 医疗用语是美妆广告的“红线”。 宜兴孙某案、绍兴金乌玉案、崇阳御升广盈案均因使用“有效缓解胃炎”“活血化瘀”“杀菌消炎”“温补阳气、通经活血”等医疗用语被处罚。《广告法》第十七条明确禁止非医疗广告使用医疗用语，美妆经营者须严格审查广告文案，避免暗示产品具有治疗作用。
- 2. 虚假功效宣传处罚力度大。 绍兴金乌玉案罚款高达50万元，泸州韩美案合并罚款近28万元，苏州开禧案罚款20万元，显示监管部门对美妆领域虚假功效宣传采取高压态势。经营者对产品功效的宣传必须有充分依据，不得虚构或夸大。
- 3. 普通化妆品不得宣传特殊用途功效。 陈剑力案、毛冉冉系列案、林福平案均因将普通化妆品宣传具有“美白”“祛斑”“防晒”等特殊用途化妆品功效而被认定为欺诈。根据《化妆品卫生监督条例》及相关规定，只有取得特殊用途化妆品批准文号的产品才能宣称具有美白、祛斑、防晒等功效。
- 4. 微信朋友圈广告须合规。 韦彩群案、俞俊玲案、常某建案均涉及通过微信朋友圈发布违法广告。韦彩群案中法院将罚款从20万元变更为3万元，常某建案中法院撤销了20万元罚款，说明微信朋友圈小范围发布广告的处罚需考量实际影响力，但经营者仍应确保广告内容合规。
- 5. 处罚对象认定须准确。 河南聚美化妆品案中，法院认定市监局未能证明系以公司名义发布广告，撤销处罚决定。行政机关在查处微信朋友圈广告时，须准确认定广告发布主体。
- （三）保健品领域：仍是执法高压区，会销和网络营销是重点监管对象
- 1. 会销模式是重点监管对象。 宜兴某服务部案、楚雄四世同堂案、高青华康案、济宁婧港案、缙云王志虎案、常州颐圣堂案、沧州东方红案均涉及以会议、讲座、免费体验等形式向老年人销售保健品并虚假宣传治疗功效。此类案件通常适用《反不正当竞争法》第八条，罚款起点为20万元，部分案件罚款高达50万元。
- 2. 普通食品不得宣称疾病预防治疗功能。 成都青羊区案中鸡蛋标签涉及疾病预防、治疗功能即构成违法；张某甲案中果汁饮品宣传治疗癌症被处罚；何某案中枫籽油宣传调理疾病被处罚。无论是保健食品还是普通食品，均不得在广告或标签中宣称疾病预防、治疗作用。
- 3. 网络营销虚假宣传风险高。 重庆某生物科技案中通过抖音平台宣传保健品功效无依据被处罚；何某案中通过网络宣传保健品使用极限词被处罚。随着直播带货、短视频营销的普及，保健品网络营销的合规风险日益突出。
- 4. 疫情期间违法行为从重处理。 鄢陵县婴智杰案中，当事人在新冠肺炎疫情期间通过微信朋友圈宣传普通食品可“预防流感”，被市监局拟罚款15万元。法院虽以过罚相当原则不准予执行剩余部分，但疫情期间的违法宣传行为仍受到监管部门的高度关注。
- 5. 保健食品标签说明书须与注册内容一致。 南宁武鸣案中保健食品标签标示涉及疾病预防、治疗功能字样，违反了《食品安全法》第七十八条的规定。保健食品的标签、说明书内容须与注册或备案内容一致，不得涉及疾病预防、治疗功能。
