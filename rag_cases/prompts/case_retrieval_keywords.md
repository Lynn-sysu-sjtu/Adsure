# 广告合规案例检索提示词表（8 个缺口场景）

> 用途：
> 1. 浙江处罚结果 API `searchPunishList`：POST `https://xzcf.zjzwfw.gov.cn/api-gateway/jpaas-punishment-server/open-api/punishment/searchPunishList`，
>    字段 `xzcfws_name`（案名）为主检索词、`bxzcf_name`（当事人）为补充、`begindate/enddate` 限定日期。
> 2. 通用 RAG 检索：把每组的「RAG 查询」作为 `/cases/retrieve` 的 content。

说明：
- 浙江 API 的「广告」会命中城市管理类（张贴广告、散发广告），要用下面的**强场景词 + 排除词**把结果收敛到商业广告处罚。
- 检索词给「词面变体」，命中率优先；命中后再按案名人工筛选。

---

## 1. 未成年人保护
- 检索词：`未成年` `儿童` `小学生` `幼儿园` `青少年` `学生` `诱导未成年人` `未成年人消费`
- 排除词：`儿童食品`（若只想游戏/广告类）`交通安全` `校园安全`
- 浙江 API：`xzcfws_name=未成年`、`xzcfws_name=儿童`
- RAG 查询：`广告 诱导未成年人消费 未成年人保护 游戏 广告`

## 2. 版号 / 防沉迷
- 检索词：`版号` `游戏版号` `防沉迷` `实名制` `网络游戏` `未实名` `未成年人防沉迷`
- 排除词：`网吧`（若只要广告）`身份证`（多数是公安处罚）
- 浙江 API：`xzcfws_name=游戏版号`、`xzcfws_name=防沉迷`、`xzcfws_name=网络游戏`
- RAG 查询：`网络游戏 版号 防沉迷 实名制 广告`

## 3. 平台规则类
- 检索词：`小红书` `抖音` `快手` `天猫` `京东` `拼多多` `美团` `平台规则` `信息流广告` `直播带货`
- 排除词：无（平台名用于召回，再按“广告/宣传”筛选）
- 浙江 API：`xzcfws_name=直播带货`、`xzcfws_name=信息流广告`、`bxzcf_name=…`（平台方当事人）
- RAG 查询：`直播带货 信息流广告 平台 广告 处罚`

## 4. 广告代言
- 检索词：`代言` `明星代言` `网红推荐` `代言人` `广告代言人` `推荐官` `体验官` `直播带货`
- 排除词：`建筑` `房产`（若只要快消/美妆/游戏）
- 浙江 API：`xzcfws_name=代言`、`xzcfws_name=直播带货`
- RAG 查询：`广告代言人 代言 广告 处罚`

## 5. 化妆品可食用宣称
- 检索词：`可食用` `食品级` `可吃` `化妆品` `儿童化妆品` `润唇膏` `口红可食用`
- 排除词：`食品安全`（那是食品监管，不是化妆品可食用宣称）
- 浙江 API：`xzcfws_name=化妆品`、`xzcfws_name=可食用`、`xzcfws_name=儿童化妆品`
- RAG 查询：`化妆品 可食用 食品级 广告 处罚`

## 6. 买赠规则
- 检索词：`买一送一` `买赠` `赠品` `满减` `附赠` `赠送` `促销广告`
- 排除词：`彩票` `抽奖`（可另归有奖销售）
- 浙江 API：`xzcfws_name=买赠`、`xzcfws_name=促销广告`、`xzcfws_name=赠品`
- RAG 查询：`买赠 满减 促销广告 处罚`

## 7. 游戏收益 / 提现
- 检索词：`提现` `游戏收益` `日赚` `赚钱` `充值得` `返利` `游戏广告` `虚假提现`
- 排除词：`P2P` `金融`（若只要游戏）
- 浙江 API：`xzcfws_name=提现`、`xzcfws_name=游戏广告`、`xzcfws_name=虚假宣传`
- RAG 查询：`游戏 提现 收益 虚假宣传 广告 处罚`

## 8. 数据引证
- 检索词：`引证` `引用数据` `好评率` `销量` `下载量` `数据来源` `虚假数据` `实验数据` `临床数据`
- 排除词：`年报` `统计`（多数非广告处罚）
- 浙江 API：`xzcfws_name=虚假宣传`、`xzcfws_name=数据`、`xzcfws_name=好评率`
- RAG 查询：`广告 数据引证不规范 虚假宣传 处罚`

---

## 通用兜底词（优先于上面的长尾词）
`违法广告` `虚假广告` `虚假宣传` `医疗用语` `绝对化用语` `保健食品` `化妆品` `网络广告` `互联网广告`

## 使用建议
1. 浙江 API 每个关键词翻页 `pageNo=1..N`、`pageSize=20`，`begindate/enddate` 设近三年。
2. 同一场景用 2–3 个变体词各查一遍，按 `xzcfws_name` 去重（`unid`/`guid` 唯一）。
3. 命中后点进 `punishDetail` 取全文，只保留「处罚决定书」事实；跨部门（未成年人/版号）标注为司法/行政参考，不当市场监管处罚事实。
