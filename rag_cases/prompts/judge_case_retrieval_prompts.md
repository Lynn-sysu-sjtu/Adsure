# 评委测试案例检索提示词

> 适用范围：`JUDGE-GAME-001`、`JUDGE-COSM-001`、`JUDGE-HF-001`。
>
> 目标：为广告合规 AI 的 production RAG 补充可公开回溯、可人工复核的行政处罚案例；不得把媒体报道、律所文章或未核验司法案例直接写入 production。

## 一、通用案例来源检索提示词

```text
你是广告行政处罚案例库的来源核验员。请围绕我提供的待审广告场景，检索中国大陆公开的广告行政处罚案例。

检索目标：找到与待审广告在“产品或服务类型、广告渠道、违法宣称、监管认定逻辑”方面相似的行政处罚案例，而不是只找法条或评论文章。

来源优先级：
P0：国家市场监督管理总局公开典型案例；
P1：地方市场监督管理局、地方人民政府、国家企业信用信息公示系统公开的行政处罚决定书或处罚信息；
P2：信用中国公开处罚信息；
P3：法院裁判文书、媒体或律所文章仅作线索，不能作为处罚事实的主来源。

硬性要求：
1. 不得编造案例、案号、处罚机关、处罚金额、法条或 URL。
2. 不得把民事判决、消费者投诉或媒体报道冒充行政处罚决定。
3. 每条结果必须提供可以直接打开的 source_url；如没有政府或信用平台正式页面，标记为 candidate，不得标记 approved_for_rag=true。
4. 区分“处罚决定明确引用的法条”和“根据事实推定可能适用的法条”。推定条款必须标记 pending_legal_review。
5. 同一案件被多家媒体转载时只保留一条，以处罚机关或信用平台页面为主。
6. 如果没有符合条件的正式案例，明确返回 cases=[]，并列出已使用的检索式和缺口，不得用低质量结果补位。

请按以下 JSON 数组返回，每条包含：
case_id、title、source_name、source_url、publish_date、decision_date、case_number、penalty_authority、party_name、industry、product_or_service、ad_channel、risk_dimensions、illegal_claims、facts_summary、legal_basis、penalty_result、penalty_amount、regulatory_logic、mapped_rule_ids、keywords、vector_text、review_status、source_verification_status、approved_for_rag、raw_text_path、evidence_boundary。

待审广告场景：
{{SCENE}}
```

## 二、游戏案例：爆率与奖励承诺

### 2.1 官方来源检索提示词

```text
使用“通用案例来源检索提示词”的全部约束，检索以下场景：

待审物料：网络游戏买量图片广告，文案为“开局十连抽，爆率拉满，神装随便出”；补充背景为“充值即可获得高爆率装备”；投放渠道为抖音、小红书。

目标类案特征：
1. 网络游戏、手游、抽卡、十连抽、装备掉落、充值奖励或福利码广告；
2. 对抽取概率、掉落概率、装备获取概率作绝对化或确定性承诺；
3. 广告宣称与游戏内实际概率、保底机制、领取条件或随机机制不一致；
4. 未清楚披露概率、限制条件或实际奖励规则；
5. 市场监管部门认定构成虚假或引人误解广告、广告允诺不准确，或相关概率宣传违法。

优先检索式：
- site:samr.gov.cn 游戏 广告 爆率 行政处罚
- site:gov.cn 市场监督管理局 游戏 抽卡 概率 广告 处罚
- site:*.gov.cn 市场监管 游戏 “十连抽” 处罚
- site:*.gov.cn 市场监管 游戏 “爆率” 虚假宣传
- site:creditchina.gov.cn 游戏 抽奖概率 行政处罚
- “游戏广告允诺不准确” 市场监督管理局
- “充值送神兽” 广告 罚款 市场监管

排除：
- 只有玩家败诉或合同纠纷、没有行政处罚事实的民事案件；
- 只有媒体转述、无法回到处罚机关页面的结果；
- 与游戏无关的普通盲盒案例，除非监管逻辑确实涉及概率公示且明确标注为跨行业参考。

期望至少找到 1 条正式行政处罚案例；如只能找到司法参考，放入 candidates 并标记 case_nature=judicial_reference_not_admin_penalty、approved_for_rag=false。
```

## 三、美妆案例：侮辱消费者、违背社会良好风尚

### 3.1 官方来源检索提示词

```text
使用“通用案例来源检索提示词”的全部约束，检索以下场景：

待审物料：美白精华降价促销图片广告，文案为“我们的美白精华一降价你还不是和狗一样跑过来”；投放渠道为小红书、抖音。

目标类案特征：
1. 广告为吸睛引流，将消费者比作“狗”或使用其他贬损、侮辱消费者人格的表达；
2. 市场监管机关认定广告内容妨碍社会公共秩序或者违背社会良好风尚；
3. 涉及《中华人民共和国广告法》第九条第（七）项及相应责任条款；
4. 行业可以是美妆、电商促销、消费电子或其他商品。该风险属于通用广告内容风险，不要求历史案例与待审商品同品类。

已知线索，仅用于定位官方来源，不得直接当作已核验结论：
- 案号：沪市监静处〔2026〕062026000257号；
- 当事人：上海百事得电子有限公司；
- 处罚机关：上海市静安区市场监督管理局；
- 涉案文案：“当我一降价，你还不是像狗一样跑过来”；
- 目标是找到上海市静安区市场监督管理局、上海市市场监督管理局、国家企业信用信息公示系统或信用中国的正式页面。

优先检索式：
- “沪市监静处〔2026〕062026000257号”
- site:sh.gov.cn “062026000257”
- site:scjgj.sh.gov.cn 上海百事得电子有限公司 行政处罚
- site:gsxt.gov.cn 上海百事得电子有限公司 处罚
- site:creditchina.gov.cn 上海百事得电子有限公司
- site:*.gov.cn “像狗一样跑过来” 行政处罚

输出时特别核对：法条应表述为“第九条第（七）项”或“第九条第一款第七项”，不得写成“第九条第七款”。
```

## 四、保健食品案例：普通食品宣称治疗癌症

### 4.1 正式案例补充检索提示词

```text
使用“通用案例来源检索提示词”的全部约束，检索以下场景：

待审物料：普通果汁饮品，无保健食品批准文号，在微信朋友圈宣传“治疗肝癌、肺癌、结肠癌等80%-90%癌症病类”。

目标类案特征：
1. 普通食品、饮料、固体饮料、果汁、驼乳粉等非药品宣称治疗癌症或其他疾病；
2. 朋友圈、微信群、会销、短视频或直播渠道；
3. 市场监管机关明确认定普通食品广告涉及疾病治疗功能、虚假宣传或使用医疗用语；
4. 优先寻找市场监管总局典型案例和地方市场监管局处罚决定。

优先检索式：
- site:samr.gov.cn 普通食品 治疗癌症 违法广告 典型案例
- site:*.gov.cn 市场监管 果汁 治疗癌症 广告 处罚
- site:*.gov.cn 市场监管 普通食品 朋友圈 疾病治疗 处罚
- site:creditchina.gov.cn 普通食品 疾病治疗 广告

本场景已有市场监管总局正式案例可用于 production 召回；新增结果必须避免重复收录同一处罚事件。
```

## 五、入库复核提示词

```text
请审查以下结构化案例是否允许进入 production RAG。

逐项检查：
1. source_url 是否为处罚机关、政府、国家企业信用信息公示系统或信用中国的可访问页面；
2. 标题、案号、处罚机关、当事人、违法事实、处罚结果和处罚金额是否能从原文直接核对；
3. raw_text_path 是否保存了可回溯原文；
4. legal_basis 中哪些是原文明确引用，哪些只是适用性推定；
5. 是否属于行政处罚案例，而非民事判决、评论文章或媒体报道；
6. vector_text 是否为自然语言场景描述且没有关键词堆砌；
7. 是否存在同一案件重复收录。

仅当全部生产门禁满足时返回：
{
  "review_status": "approved",
  "source_verification_status": "source_verified",
  "approved_for_rag": true,
  "production_exclusion_reasons": []
}

否则返回：
{
  "review_status": "pending_review",
  "source_verification_status": "pending_official_source_lookup",
  "approved_for_rag": false,
  "production_exclusion_reasons": ["逐条列明未通过原因"]
}

待复核案例：
{{CASE_JSON}}
```
