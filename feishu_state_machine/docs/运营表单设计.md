# 运营提交表单设计 — A方案条件显示

## 一、设计原则

1. **一份表单，三套字段**：靠"行业领域"作为开关，选什么行业才显示什么行业的专属字段。
2. **运营只看到 ① 段**：表单视图只展示运营提交区字段（27个），AI/法务/流转字段全部隐藏。
3. **写回同一张表**：表单提交 → 落到 `审心广告物料合规审核台 v3` 的同一行记录。

## 二、表单创建步骤

### Step 1 — 在多维表格里新建表单视图
1. 打开 https://dcnhexeh6nru.feishu.cn/base/GpDLbQMlVaRaKjsnKsjcrmKLntg
2. 左下角"+ 新建视图" → 选"表单"
3. 命名为 **"运营物料提交表单"**

### Step 2 — 字段顺序与表单字段说明

按下面顺序在表单里上下排列（直接拖动字段顺序）：

| 顺序 | 字段名 | 必填 | 说明文字（给运营看的提示） |
|---|---|---|---|
| 1 | ①运营·行业领域 | ✅ | 选择物料所属行业，决定下方需要填写的专属字段 |
| 2 | ①运营·物料编号 | ✅ | 自动生成或填运营内部编号 |
| 3 | ①运营·物料内容 | ✅ | 粘贴广告文案/详细描述 |
| 4 | ①运营·物料附件 | ❌ | 上传图片、视频、详情页截图 |
| 5 | ①运营·紧急程度 | ✅ | 普通 / 加急 |
| 6 | ①运营·是否启用AI预审 | ✅ | 启用后系统先做轻量预审，再交法务 |
| 7-12 | 美妆专属（6个）| 条件 | 仅当行业=美妆时显示 |
| 13-18 | 游戏专属（6个）| 条件 | 仅当行业=游戏时显示 |
| 19-24 | 保健食品专属（7个）| 条件 | 仅当行业=保健食品时显示 |

> **注**：①运营·提交人 / 提交时间 由系统自动填，**不放表单**。

### Step 3 — 配置条件显示规则（关键）

在表单编辑页，**点击每一个行业专属字段** → 右侧面板找到"显示条件"或"高级设置 → 字段联动" → 配置如下：

#### 美妆专属字段（6个均设置同一条规则）
- 触发字段：`①运营·行业领域`
- 条件：等于
- 值：`美妆`

涉及字段：
- ①美妆·物料类型
- ①美妆·投放平台
- ①美妆·产品品类
- ①美妆·产品备案名称
- ①美妆·物料涉及场景
- ①美妆·核心宣称功效

#### 游戏专属字段（6个）
- 触发字段：`①运营·行业领域` = `游戏`

涉及字段：
- ①游戏·物料类型
- ①游戏·投放平台
- ①游戏·产品品类
- ①游戏·游戏名称
- ①游戏·物料涉及场景
- ①游戏·IP名称

#### 保健食品专属字段（7个）
- 触发字段：`①运营·行业领域` = `保健食品`

涉及字段：
- ①保健食品·物料类型
- ①保健食品·投放平台
- ①保健食品·产品品类
- ①保健食品·物料涉及场景
- ①保健食品·核心宣称功效
- ①保健食品·产品备案名称
- ①保健食品·批准文号

### Step 4 — 隐藏非运营字段

表单视图默认会把所有字段都展示，需要把以下字段全部**移除出表单**（不是隐藏，是从表单字段列表里删除）：

- ②AI预审·* （6个）
- ③AI审核·* （10个）
- ④法务·* （9个）
- ⑤流转·* （5个）
- ①运营·提交人 / 提交时间（系统自动填）

剩下的就是运营会看到的字段。

### Step 5 — 表单基础设置

| 设置项 | 推荐值 |
|---|---|
| 表单标题 | 审心 · 广告物料合规审核提交单 |
| 表单描述 | "提交后系统将根据是否启用AI预审进入对应流程。加急物料2小时内法务响应。" |
| 提交后提示 | "提交成功！物料编号已记录，可在 [工作台-我的物料] 查看进度。" |
| 是否允许匿名提交 | 否（需登录飞书账号，自动写入提交人） |
| 是否限制每人提交次数 | 不限制 |

## 三、表单使用流程

```
运营打开表单链接
  ↓
选 行业领域 = 美妆/游戏/保健食品
  ↓
对应的6-7个专属字段自动出现，其他行业字段隐身
  ↓
填写完毕，点击提交
  ↓
新建一行记录到 v3 多维表格
  ↓
（如启用AI预审）触发自动化流程，写回 ②AI预审·* 字段
  ↓
法务在多维表格里看到这条记录，进行审核
```

## 四、与多维表格分组的关系

- **多维表格里**：57个字段按 ①/②/③/④/⑤ 五段分组（手动归组或开权限后跑 group_fields_v3.py）
- **表单视图里**：只展示 ① 段的27个字段，其中行业专属字段按A方案条件显示

两套视图各自独立，不互相干扰。
