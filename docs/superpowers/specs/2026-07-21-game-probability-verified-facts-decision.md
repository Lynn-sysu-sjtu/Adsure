# 游戏概率宣传已核验事实边界决策

## 决策

本次采用保守方案：不将飞书字段 `①运营·补充背景资料` 视为已经独立核验的客观事实，不仅凭该字段将概率宣传判定为 `confirmed_violation`。

## 原因

- 补充背景资料由运营提交，可能是业务说明、待核实信息或不完整摘要；
- 如果直接将其当作定案证据，可能因输入错误而产生错误定性；
- 当前 `/audit` 契约没有单独的“已核验事实”输入，事实 RAG、后台配置查询和人工证据确认也不在本次范围。

## 当前行为

- 对“开局十连抽，爆率拉满，神装随便出”，`GAME-FALSE-004` 输出 `needs_fact_verification`；
- 需核验实际抽卡概率、奖池配置、道具掉落概率、保底机制及相关适用条件；
- 规则内保留第二判断节点：当后续已核验事实通道证明广告承诺与实际机制明显不符时，再输出 `confirmed_violation`。

## 兼容性

本决策不新增 `/audit` 输入或输出字段，不修改飞书状态机，不将非《广告法》规则纳入召回。
