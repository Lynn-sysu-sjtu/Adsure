# 广告法 vs 反不正当竞争法：虚假宣传适用边界

> 用于指导 `regulations.json` 法条入库和 LLM prompt 设计。

---

## 一、两法关系

广告法和反法在虚假宣传上是**特殊法与一般法并存**，不是互斥关系，有各自独立适用的空间，也可双重适用。

---

## 二、区分标准

### 标准一：行为形式

| 行为形式 | 适用法律 |
|---|---|
| 通过广告媒介（付费广告位、直播间植入、硬广等）向不特定公众发布 | 广告法第28条为主 |
| 官网产品页、新闻稿、非付费 KOL 种草文、内部推介材料 | 反法第8条为主（广告法无法覆盖） |
| 两种形式兼有 | 两法并用，实践中按较重处罚 |

### 标准二：有无竞争维度

| 内容特征 | 适用法律 |
|---|---|
| 单纯自夸、功效夸大 | 广告法第28条 |
| 虚假对比宣传（声称比竞品好） | 反法第8条 |
| 明确贬低、诋毁竞争对手商誉 | 反法第11条（商业诋毁，独立条款） |

### 标准三：处罚量级

| 法律 | 一般违法 | 情节严重 |
|---|---|---|
| 广告法第55条 | 20万-100万 | 100万-200万 + **可吊销营业执照** |
| 反法第20条 | 10万-50万 | 50万-300万 |

> 广告法处罚更重（吊销营业执照是核弹级），但反法上限（300万）反而更高。

---

## 三、快速判断框架

```
虚假宣传行为
│
├── 是否涉及贬低/诋毁竞品？
│   └── 是 → 反法第11条（独立适用，与广告形式无关）
│
├── 是否是付费广告形式投放？
│   ├── 是 → 广告法第28条为主，可与反法第8条并用
│   └── 否（软文、官网、非付费内容）→ 反法第8条为主
│
└── 是否有竞品对比（非贬低，只是比较）？
    └── 是 → 反法第8条优先（引人误解的对比宣传）
```

---

## 四、典型场景对应

| 文案示例 | 适用法律 | 说明 |
|---|---|---|
| "本品是全网销量第一的精华" | 广告法第9条 + 第28条 | 单纯自夸，广告形式，主适用广告法 |
| "XX精华比SK-II效果好30%，经权威机构认证" | 反法第8条（+ 广告法第12条） | 涉及竞品对比，反法权重更大 |
| "SK-II小红瓶含有致癌成分" | 反法第11条 | 商业诋毁，与广告形式无关 |
| 品牌自媒体非付费软文："敷完马上有效果" | 反法第8条 | 非广告形式，广告法执法机关无直接管辖权 |

## 五、对项目的影响

### 当前状态（2026-07）
`regulations.json` 中无反法条目，系统对反法场景完全无感知。

### 优先级判断
- 反法第11条（商业诋毁）：判断标准相对清晰（有没有贬低竞品），错误代价极高，必须路由法务。**建议 MVP 后第一批加入。**
- 反法第8条（对比宣传）：判断主观性强，LLM 误判率较高。**放在反法第11条之后。**

### 接入时需要的改动
1. `regulations.json` 增加 `REG-UCL-001`（反法第8条）和 `REG-UCL-002`（反法第11条），`default_routing` 均设为 `"法务"`
2. `fields_v4.py` 增加 `F_宣传形式` 字段（付费广告 / 自有账号内容 / 对比测评 / 其他），影响法律适用分支
3. `predictor.py` system_prompt 补充：涉及竞品对比或贬低竞品时，违规类型须标注反法第8条或第11条，routing 强制设为法务
