# 飞书机器人接线手册（视频审核 → 多维表格）

> 目标读者：持有飞书开放平台应用凭据的队友。按本文操作约 30 分钟完成接线。
> 后端 API 已全部就绪（`sprint-a-plus` 分支），本文只覆盖「飞书侧怎么调它」。

## 0. 前置状态

- 后端服务：`sprint-a-plus` 分支，`PYTHONPATH=backend .venv-handoff/bin/python -m uvicorn app.api:app --port 8540`
- 契约：飞书 `audit_response_v0.2`（与规则引擎 `/audit` 同 schema，jsonschema 校验已内置）
- 轮询流程：`POST /api/jobs`（202）→ 按 `retry_after_ms` 轮询 `poll_url` → `terminal=true` 且 `audit_response_ready=true` 时取 `audit_response_url`

## 1. 需要的凭据（找管理员开通）

| 凭据 | 用途 | 放哪里 |
|---|---|---|
| 飞书应用 `app_id` / `app_secret` | 机器人收发消息、卡片回调 | 飞书开放平台 → 应用凭证 |
| 多维表格 `app_token` / `table_id` | 视频附件上传、审核字段回写 | 表格 URL 里 |
| `X-API-Key`（可选） | 给后端 API 加鉴权 | 自定义环境变量 |

⚠️ 凭据只放 `.env`（已 gitignore），不进代码、不进飞书脚本日志。

## 2. 飞书开放平台配置（控制台操作）

1. **事件订阅**：订阅「多维表格记录变更」事件（`bitable.v1.record.changed_v1`），
   请求地址填你的回调服务 URL（需公网可达，或用长连接模式）。
2. **权限**：`bitable:app`（读写表）、`im:message`（发卡片）、`im:resource`（读视频附件）。
3. **机器人能力**：开启「机器人」，配置卡片请求网址（卡片按钮回调）。

## 3. 视频审核字段映射（多维表格 → API）

运营在表格里新建一行后，机器人从记录读这些字段调 API：

| 表格字段 | API 参数 | 说明 |
|---|---|---|
| 视频附件 | `video`（下载后 multipart 上传） | 机器人先经飞书 API 下载附件，再转发给审核服务 |
| 行业 | `industry` | 枚举：美妆/游戏/保健食品/通用 |
| 投放平台 | `platforms_json` | JSON 数组，如 `["抖音"]` |
| 补充背景 | `supplement` | 已取得的认证/授权说明 |
| 记录 ID | `record_id` | **必传**——重试幂等的依据 |

## 4. 审核结果回写（API → 表格）

轮询到 `terminal=true` 后：

1. `GET audit_response_url` 拿 v0.2 结果。
2. 回写表格字段（与文案审核同一套字段）：
   - `预审_风险等级` → 风险等级列
   - `预审_命中要点` → 摘要列
   - `审核_推荐违规类型` → 违规类型列
   - `matched_rules[].default_routing` → 路由列（任一「法务」→ 整体法务）
3. **卡片加「查看逐秒证据」按钮**，链接到：
   ```
   <后端地址>/api/jobs/{job_id}/report-page?report=/api/jobs/{job_id}/report
   ```
   （`report-page` 返回前端回看页，`?report=` 深链自动载入报告；
   视频本体走 `/api/jobs/{job_id}/media`，回看页已支持）

## 5. 裁决回流（Step6）

法务在卡片/表格里裁决后，机器人调：

```
POST /api/jobs/{job_id}/adjudication
{"finding_index": 0, "action": "false_positive",
 "reason": "属客观分级描述", "adjudicator": "法务-张某",
 "matched_text": "国家级"}
```

`action` 枚举：`confirmed_violation / false_positive / missed_risk /
not_applicable / needs_more_evidence / ip_confirmed / ip_rejected`。
裁决自动沉淀到 `data/rules/feedback/*.jsonl`（词库/类案/IP 三库分流）。

## 6. 验收清单

- [ ] 表格新建行 + 传视频 → 机器人收到事件并调 API
- [ ] 轮询到终态 → 表格回填风险等级/摘要/路由
- [ ] 卡片「查看逐秒证据」→ 浏览器打开回看页，时间轴可点、取证框可见
- [ ] 法务裁决 → `data/rules/feedback/` 出现对应 JSONL 行
- [ ] 同一 `record_id` 重复触发 → 返回同一 `job_id`（幂等）
